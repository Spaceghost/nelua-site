Inspect the full snapshot

A current footprint

Original public Nelua source on each indexed repository's default branch, across all time. Blank and comment-only lines are excluded.

One copy counts

Forks, known vendored and generated files, and exact duplicate source are excluded. The snapshot records coverage and unavailable repositories.

Projects belong to a community

Public projects aggregate under their GitHub repository owner, with project links and pinned commits. Private totals count only current code attributed to commits authored by the participating owner; other authors and unlinked identities are excluded.

Coverage details are included in the downloadable snapshot.
