The compiler

Upstream Nelua, tracked closely, plus the pieces a self-hosted libc and freestanding targets asked for.

Spaceghost/nelua-lang is a fork of edubart/nelua-lang at commit a584505 (2025-06-24). Each addition lands with specs in spec/ and a page under docs/pages/, and the gate runs upstream's make test together with nelibc's smoke matrix against the freshly built compiler.

What the fork adds

Everything below is opt-in syntax or tooling. Code written for upstream Nelua compiles unchanged.

Const pointers

*const T maps to C const T*. Reads through it are read-only; dropping const needs an explicit cast. The analyzer checks constness on the pointer type before implicit dereference.

overview ↗

pragmas.freestanding

A compiler-enforced runtime-free profile. It implies nogc and noentrypoint, traps on abort, and rejects heap, process, stdio and main symbols at compile time. nelibc's host profile and Drift's kernel build on it.

runtime-free guide ↗

--target <triple>

Cross compile with clang or zig cc. The triple reaches the type-size probe, the cache hash and the compile, so a build for another architecture never reuses the host's cached sizes.

tools/nelua-bindgen

Generates <cimport> bindings from C headers with libclang: typedef struct tags on forward declarations, array parameters decayed to unbounded array pointers, committed expected output for the sample.

Variants

Tagged unions as variant(A, B) or the shorthand A|B through require 'variant'. A variant is a plain record: a uint8 tag followed by a C union, so it works without the GC.

require 'variant'
local Shape = @variant(integer, string)
local s: Shape = 'circle'
if s:is(string) then print(s:get(string)) end

Closures

Anonymous functions capture upvalues by value as closure records. The rewrite is deferred until captured types resolve. Older releases of the fork (and upstream) reject upvalue access in nested functions; nebox was written against one of those, which is why it uses records and module-level locals instead.

Toolchain and editor support

A compact C codegen profile for distributable output, Tree-sitter and TextMate grammars under tools/ (the Tree-sitter scanner is itself written in Nelua), and a binary cache that also hashes imported C sources so a changed header rebuilds.

Install

Nelua needs Git, a C compiler and make. The fork builds the same way upstream does.

git clone https://github.com/Spaceghost/nelua-lang
cd nelua-lang
make
sudo make install   # or: make install PREFIX=$HOME/.local
nelua --version

Pinning: the nelibc gate and nebox's container builds run Nelua 3c29419, the merge of the Tree-sitter work. Newer fork commits add variants and closures on top; nelibc and nebox do not yet require them.

How changes are gated

Specs
make test runs upstream's spec suite plus one spec file per addition (const pointers, freestanding, target, bindgen, variant, closures).
Consumers
nelibc's seven-profile smoke matrix is rebuilt against the fresh compiler before a change is merged.
Runtime-free audits
A standalone GCC and Clang workflow links the freestanding examples and checks the emitted symbols: no allocator, no GC, no entry point.
Upstream
The fork rebases rather than diverges; language additions are kept small enough to offer upstream.
