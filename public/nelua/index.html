Nelua

Lua syntax for native programs.

Nelua is a statically typed systems programming language. The compiler infers types, translates your code to C, and builds native executables. Call C libraries directly or use Lua to generate code at compile time.

Upstream Nelua

Advance a world by one generation

function GameState:step()
  for y=0,GRID_HEIGHT-1 do
    for x=0,GRID_WIDTH-1 do
      self.b:set_alive(x, y, self.a:next(x, y))
    end
  end
  self.a, self.b = self.b, self.a -- swap fields
end

Each cell reads its neighbors from field a and writes its next state to field b. A multiple assignment swaps the two field pointers when the generation is complete.

Theseus Init

Start the console

local flags = MS_NODEV | MS_NOEXEC | MS_NOSUID
mount_one('proc', '/proc', 'proc', flags)
mount_one('sysfs', '/sys', 'sysfs', flags)
setenv('PATH', '/bin:/sbin', 1)
report('theseus: starting console shell')

Linux gives PID 1 the job of bringing up userspace. Theseus mounts the process and device filesystems before it opens the Nebox shell.

Drift

Build an instruction set at compile time

## local names = {'HALT','LIT','MOV','ADD','SUB','MUL','DIV','AND','OR',
##                'XOR','SHL','SHR','LD8','ST8','LD32','ST32','JMP',
##                'JEQ','JNE','JLT','IO','EVENT','SLEEP'}
## for i, name in ipairs(names) do
local asm.#|name|#: uint8 <comptime> = #[i-1]#
## end

The lines marked ## run Lua inside the compiler. Each pass splices a name into a Nelua declaration, giving the driver assembler a typed constant for every opcode.

local asm.HALT: uint8 <comptime> = 0

Melodica extension

Give a browser extension its own allocator

local function mx_alloc(n: usize): *[0]byte <cexport, codename 'mx_alloc'>
  local size: usize = n
  if size == 0 then size = 1 end
  size = (size + 7) & ~7_usize
  if size > ARENA_SIZE - st.arena_top then return nilptr end
  local start: usize = st.arena_top
  st.arena_top = start + size
  return (@*[0]byte)(&st.arena[start])
end

Melodica exports this function from its WebAssembly module. It rounds each allocation up to eight bytes and hands the caller a pointer into a fixed arena.

Core

Language

Compiler

A Nelua compiler fork with exhaustive matching, ownership, compile-time evaluation and file-local syntax extensions.

C library

nelibc

A C library written in Nelua, with hybrid builds over glibc, musl and Cosmopolitan and a standalone Linux runtime.

Userland

nebox

Unix applets in a single static executable linked against standalone nelibc.

Boot manager

neboot

A UEFI boot menu written in Nelua. Start Cascadia with Theseus Init or OpenRC recovery, or chainload another EFI application.

Shell

nsh

The interactive POSIX shell included in nebox, with command completion, searchable history and job control.

Compiler driver

necc

Compile C and Nelua against standalone Nelibc or run Lua from the staged SDK.

Linker

nelinker

Link x86-64 ELF objects into Linux executables or PE32+ EFI applications.

Build runner

nebuild

Run incremental, parallel builds from a build.ne dependency graph.
