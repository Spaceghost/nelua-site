Theseus init

A Linux service supervisor written in Nelua. CUE describes services and their dependencies. Theseus starts them in order and waits for their readiness checks.

Time to a working serial shell

Theseus Init is a related project outside Nelua core. In the Cascadia Core developer image it starts the Nebox console. On 22 November 2026 five alternating pairs under QEMU 10.2.2 TCG took a median 6.27 s with the gzip release image and 10.13 s with the same cpio bytes encoded as legacy LZ4. The clock starts at process launch and stops when a shell command returns.

On the i7-11700F, gzip ranged from 5.39 to 11.68 s and LZ4 from 7.97 to 28.75 s. The 21 November i7-9700K favored LZ4. The separate gzip control on this host took 5.80 s for a direct shell and 6.25 s with Theseus.

Supervise services

The userspace daemon runs foreground services and native targets. It tracks child processes with Linux pidfds, reaps adopted children, and applies each service’s restart policy. The OpenRC adapter runs installed Alpine service scripts through the system OpenRC runtime.

theseusd --target TARGET

Boot and rescue

Theseus has an opt-in native PID 1 for isolated Linux VM testing. It starts the supervisor and opens a console rescue shell if boot fails.

The Theseus-enabled Nebox build also provides an initramfs entry point. It mounts procfs and sysfs, starts an interactive shell on the boot console, and restarts the shell when it exits.

This records a local Node.js WASM test, not an interactive browser release. No Wayland, guest Chromium or hardware acceleration is claimed. The serial browser demo above is unchanged.

Working with mounts

In the Nebox guest, use mount to attach filesystems and umount to detach them. The following example creates a temporary filesystem at the existing /mnt directory in the boot image.

/bin/nebox mount -o size=16m,mode=0755 tmpfs /mnt
/bin/nebox mount -t tmpfs
/bin/nebox umount /mnt

Use /bin/nebox mount TARGET to look up a configured target in /etc/fstab. /bin/nebox mount -T FILE TARGET selects another table.
