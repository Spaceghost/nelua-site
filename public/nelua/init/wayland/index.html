Wayland inside Theseus

Boot a Linux guest with Theseus as PID 1. Newayland, a compositor written in Nelua, draws a real Wayland test client inside the guest.

ARM64 GUEST 320 × 240 · SOFTWARE
This demo requires a browser with canvas support.

Not started. Nothing boots until you select Start Theseus.

After boot, press Space on the display or select Send Space. Both send a keypress to the guest client. This is software rendering, not a full desktop. The guest has no network connection or persistent disk.
