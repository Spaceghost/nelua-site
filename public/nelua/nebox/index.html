Using the toolbox

Shell and job control

Start an interactive shell with nebox sh -i. It supports editable history, tab completion, pipelines and background jobs. nsh adds a colored prompt and XDG history and configuration files.

Text and files

Search with grep, edit streams with sed and process records with awk. For larger jobs, sort can spill to disk, diff can compare directory trees, and tail can follow a rotating log.

Archives and checksums

Create or extract a tar archive, compress a stream with gzip, or write decompressed data to standard output with zcat. Use sha256sum to verify a file.

Known limits

Standalone locale data covers C, UTF-8 character handling and German collation. Some commands work byte by byte. Account enumeration reads the local databases. The grep -P option requires a build linked with static PCRE2.

Applet compatibility notes

Build and test

Nebox links against nelibc’s standalone archive. The conformance suite checks command output, exit status and changes to the filesystem. The coverage check tests which commands can be invoked.

Nebox repositoryConformance suite
git clone https://github.com/Spaceghost/nelibc
make -C nelibc lib-standalone-zig
git clone https://github.com/Spaceghost/nebox
make -C nebox NELIBC=../nelibc
make -C nebox NELIBC=../nelibc test

The ARM64 build supplies the shell and utilities in Cascadia Edge. The signed packages were built on Fedora and tested by running the public migration in an Alpine aarch64 guest. Stage the ARM64 base root.
