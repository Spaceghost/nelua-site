nebox

A toybox-style userland: 85 applets, one static binary, no host libc.

Spaceghost/nebox is a multicall binary written in Nelua and linked against nelibc's standalone archive. Each applet is chosen from argv[0] (a hard or symbolic link named after the applet) or from the first operand. It carries its own regex engine, stream editor, find, diff and checksum implementations, all in about 7,600 lines of Nelua.

How it is checked

Every case in tests/run.sh runs one shell command twice from identical fixture trees: once with the host's GNU coreutils, once with nebox's applet links first on PATH. stdout, the exit status and a snapshot of the resulting directory (names, modes, checksums) must match. Where the host has no reference tool, a pinned expected output is used instead.

Link recipe

Nelua emits C; zig cc links the whole nelibc standalone archive with no libc, no PIE and nelibc's own _start.

nelua -r --cc 'zig cc -mcpu=x86_64' \
  --cflags='-DNELIBC_STANDALONE -nostdlib -static \
    -ffreestanding -fno-builtin -Wl,-e,_start' \
  --ldflags='-Wl,--whole-archive \
    libnelibc-standalone-zig.a -Wl,--no-whole-archive' \
  -o nebox src/nebox.nelua
nm -u nebox   # must print nothing

What the GC situation is

The program is compiled with pragmas.nogc: nelibc has no _setjmp, which Nelua's collector needs, and a shell toolbox does not need a collector. Applets allocate with the default allocator and exit; memory is reclaimed by the kernel.

Own regex engine

POSIX basic and extended syntax with brackets, classes, intervals, groups, alternation, back-references and the GNU word escapes, as a backtracking VM in src/nebox/regex.nelua. grep, sed, expr and find share it.

Known limits

Stated rather than worked around. The full list is in the repository's README.

  • Regex matching is leftmost-first (backtracking), not POSIX leftmost-longest; this only shows with alternations whose branches are prefixes of each other. No multibyte locales.
  • date and stat print UTC: nelibc has no zone database.
  • ls prints one entry per line in every mode. du and find walk directories in sorted name order where GNU uses directory order.
  • sed has no e, M or -z; grep has no context lines; sort has no -M, -V or -h; xargs has no -P.
  • tail -f polls once a second. timeout polls the child every 2 ms instead of using signals.
  • Names for ids come from reading /etc/passwd and /etc/group directly; nelibc has no getpwuid.

Build

git clone https://github.com/Spaceghost/nelibc
make -C nelibc lib-standalone-zig
git clone https://github.com/Spaceghost/nebox
make -C nebox NELIBC=../nelibc        # build/nebox
make -C nebox NELIBC=../nelibc test   # the conformance suite

Builds and tests are recorded in a Debian 12 container with Nelua 3c29419, Zig 0.17.0 and GNU coreutils as the reference. The repository's CI runs the same suite on every push.
