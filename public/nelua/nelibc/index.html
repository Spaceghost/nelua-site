nelibc

A C library, rebuilt piece by piece in Nelua.

Replace selected libc functions with Nelua implementations and keep the rest on glibc or musl; then grow the replacement into a standalone runtime. Spaceghost/nelibc is experimental, Linux x86-64, with hybrid builds working and the standalone profile in progress. About 36,000 lines of Nelua, with x86-64 assembly for memory primitives and a handful of C adapters at the seams.

Three profiles

Hybrid

Link libnelibc-zig.a (or the GCC, musl or TinyCC variant) before the host libc. Nelibc's symbols win; uncovered ones keep coming from glibc or musl. The incremental replacement model.

make lib-zig
zig cc -Iinclude -fno-builtin app.c \
  build/libnelibc-zig.a -o app

Standalone

No host libc at all: Nelibc owns _start, the Linux x86-64 syscall backend, malloc, stdio, pthreads (a subset), locale data and math. This is what nebox links against.

make lib-standalone-zig
# -nostdlib -static, whole-archive, -Wl,-e,_start

Host

Standalone minus Linux: the same objects over a table of host callbacks (console, memory, clock, exit) for kernels and unikernels. Threads run as cooperative lanes on the host's one hardware thread. First consumer: the unmodified Bend 2 runtime that Writ compiles to.

Build and gate

Requirements
Nelua, Zig (zig cc). GCC for the GCC profile; TinyCC mob branch for the TinyCC profile.
First build
make dogfood-zig builds the hybrid archive, compiles examples/incremental.c, runs it and checks Nelibc's memcpy, strlen, strchr and strtol are the ones linked.
Matrices
make smoke-matrix (seven profiles), make dogfood-matrix (four consumers), make host-matrix, make host-bend-hello-zig.
Last recorded gate
2026-11-07 on main 125f247: Debian 12, glibc 2.36, GCC 12.2, Zig 0.17.0, Nelua dabbd9ef. 159 of 159 targets passed with no warnings: hybrid Zig/glibc, GCC/glibc and Zig/musl, standalone Zig and GCC, freestanding Zig and GCC, the host profile, and musl's libc-test against the hybrid and standalone archives. Until this run the gate script had left libc-test out although the repository's gate list includes it; a <limits.h> regression in GCC hybrid builds slipped through that gap and was fixed.
Conformance
musl's libc-test runs against the gcc and zig hybrid archives with a committed expected-failure list that only shrinks: 112 and 118 after the first slice, 31 (gcc) and 35 (zig) on main now, none of them math tests. Slice 2 fixed strftime, fnmatch, exact %La, the TZif reader's stack use and malloc_usable_size; the math slice ported musl's exp, pow, log, trigonometric, gamma and Bessel code with its exception-flag discipline, which cleared 76 math tests. A follow-up fixed the last seven: the sign of fma with a zero addend, fmaf rounding and underflow in the subnormal range, the sign of modfl's fraction, and musl ports of erfl, erfcl and exp10l. printf now formats every long double exactly: %Lf, %Le and %Lg write the full decimal expansion of the 80-bit value and round half to even, checked against glibc on 28 cases including LDBL_MAX in all 4,940 characters.
Standalone conformance
libc-test also runs against the standalone archive, where Nelibc is the whole C library: Nelibc's headers only, its own _start, libc-test's own runner with the 100 KiB stack limit. The first run passed 255 of 343 tests with GCC; after the fixes it led to (<limits.h>, <inttypes.h>, <langinfo.h>, <search.h> and <regex.h> (nebox's Pike VM engine behind the POSIX interface) for standalone, static constructors and destructors, scanf %n and ungetc pushback, cancellation points and PI mutex relock, ftello on append streams, sem_open reuse, pthread_create's EAGAIN, exit after the last pthread_exit) 300 pass with GCC and 301 with Zig, with no timeouts; with <pwd.h>/<grp.h>, <setjmp.h> and a batch of small POSIX families since, 318 pass with GCC and 319 with Zig (all 25 and 24 failures expected and listed). mktime now honours a tm_isdst that contradicts the date, as glibc and musl do, a fix found through nebox's date -d '14 days ago'. Every math test that builds passes. The rest is a written map of what is missing (dl*, iconv, shm_open, ...) and of what is still open (a posix_spawnp null-envp divergence, destroying a locked robust mutex), in docs/libc-test.md.
CPU baseline
Zig builds default to -mcpu=x86_64; override with ZIGFLAGS='-mcpu=x86_64_v3' on purpose.
