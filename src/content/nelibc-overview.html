Nelibc benchmarks

The goal is the fastest correct implementation of the libc operations programs use most. The current evidence compares glibc, musl and Cosmopolitan, each alone and with Nelibc, on the same host and consumer.

Completion

glibc: 819; musl / Zig: 793; Cosmopolitan: 399 of 1,471 tracked names exported by Nelibc. These count owned implementations, not standards compliance. Cosmopolitan deliberately delegates more stateful services.

Conformance

glibc: 301 → 325 passes; musl / Zig: 327 → 333 passes; Cosmopolitan: 279 → 302 passes in the matched functional, regression and math corpus. Build failures, runtime failures and newly failing tests are all reported.

Performance

Synthetic record parser, baseline time ÷ Nelibc time: glibc 0.75×; musl / Zig 2.23×; Cosmopolitan 2.46×. Above 1× is faster. The detailed results include memory, strings, conversion, math, allocation, formatting and sorting, including slower cases and delegated calls.

Measured 2026-11-17 UTC over 7 comparison rounds. Consumer correctness checks passed before timing.

Optimization follow-up: memchr-absent(32) 2.04×; strtol-decimal 1.51×; qsort-128-integers 1.65× faster than the previous candidate in the concurrent GCC/glibc comparison. Slower cases and alignment results are included on the detailed page.

Builds verified. The glibc, musl and Cosmopolitan builds pass integration checks. Standalone builds and Bend’s worker pool pass too. Test results and known gaps.
