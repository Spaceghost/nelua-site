Nelibc benchmarks

The goal is the fastest correct implementation of the libc operations programs use most. The current evidence compares glibc, musl and Cosmopolitan, each alone and with Nelibc, on the same host and consumer.

Completion

glibc: 819; musl / Zig: 793; Cosmopolitan: 399 of 1,471 tracked names exported by Nelibc. These count owned implementations, not standards compliance. Cosmopolitan deliberately delegates more stateful services.

Conformance

glibc: 301 → 325 passes; musl / Zig: 327 → 333 passes; Cosmopolitan: 279 → 302 passes in the matched functional, regression and math corpus. Build failures, runtime failures and newly failing tests are all reported.

Performance

Synthetic record parser, baseline time ÷ Nelibc time: glibc 1.12×; musl / Zig 3.56×; Cosmopolitan 3.91×. Above 1× is faster. The detailed results include memory, strings, conversion, math, allocation, formatting and sorting, including slower cases and delegated calls.

Measured 2026-11-21 UTC over 7 comparison rounds. Consumer correctness checks passed before timing.

Optimization follow-up: parse-record 1.46×; strtod-decimal 1.63×; memcmp-equal(4096) 1.38×; strlen(128) 1.83×; strlen(4096) 1.32×; strstr-tail(65536) 1.01× compared with the previous Nelibc build in the paired GCC/glibc run. The record parser is a synthetic workload. The 64 KiB substring controls have their own input shapes and timing loops. The complete results and input distributions are on the detailed page.
